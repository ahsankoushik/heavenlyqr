heavenlyqr (1.0.0)

Download OpenAPI specification:

Bulk QR-code generation service: submit a URL + numeric ID range, poll the resulting service request, then download the generated images.

required

Get Service Request List

query Parameters
page
integer >= 1
Default: 1
Example: page=1

1-indexed page number.

limit
integer [ 1 .. 100 ]
Default: 20
Example: limit=20

Page size.

status
string (RequestStatus)
Enum: "PENDING" "PROCESSING" "COMPLETED" "PARTIALLY_FAILED" "FAILED" "CANCELLED"
Example: status=COMPLETED

Filter by request lifecycle status.

search
string non-empty
Example: search=imkoushik.me

Case-insensitive substring match against the request URL.

sortBy
string
Default: "createdAt"
Enum: "createdAt" "updatedAt"
Example: sortBy=createdAt
sortOrder
string
Default: "desc"
Enum: "asc" "desc"
Example: sortOrder=desc
